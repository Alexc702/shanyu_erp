# 施工交付

管理项目签约后的施工基准、计划、现场记录和变动。

## Language

**施工基准**：
用于现场交付的已批准报价版本及其无价物料和选型快照。
_Avoid_: 可以在施工中任意修改的报价草稿

**施工计划**：
基于开工日期、合同工作日和阶段模板形成的时间安排。
_Avoid_: 项目阶段

**施工节点**：
施工计划中需要指定责任人并确认完成的可跟踪目标。
_Avoid_: 通知、进度文字

**进展更新**：
按施工阶段记录的时间、发布人、说明和现场照片。
_Avoid_: 施工节点确认

**工程变动**：
施工中新增、减少或替换内容的独立受控记录。
_Avoid_: 覆盖原批准报价
