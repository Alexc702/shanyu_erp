# 报价

定义项目从编辑、生成基础报价到优惠调整审批的计价、协作、版本和输出语言。

## Language

**报价**：
项目在签约前用于形成价格方案的可版本化业务记录。
_Avoid_: Excel 源文件、导出附件

**报价版本**：
一次正式生成或状态变化形成的连续版本；当前有效版本才可继续操作，历史版本只读。
_Avoid_: 浏览器保存次数、覆盖旧版本

**报价阶段**：
当前有效版本所处的草稿、已报价、已退回或已批准状态。
_Avoid_: 待定价、待补充、待审批、已审批

**草稿**：
可编辑的报价版本。首次报价直接编辑 V1；已报价或已退回后继续编辑会自动建立下一版草稿。

**已报价**：
主案完成生成前检查并确认生成的正式基础报价版本；折扣 100%、抹零 0 且未提交优惠调整审批时，不需要老板批准即可查看、打印和导出客户 PDF/XLSX。

**已退回**：
老板要求修改的只读版本；主案继续编辑时基于它建立下一版草稿。

**已批准**：
老板批准折扣/抹零调整后形成的只读基准；只有老板先打回后才能继续修改。

**报价模块进度**：
半包、主材、铂屿木作、第三方代购和定制项目的独立完成情况。V1 只实现半包模块及其他模块的边界，不臆造未提供模板字段。

**半包报价**：
按项目空间和项目级通用工程组织的施工工序价格方案。
_Avoid_: 主材 SKU、木作产品

**第三方代购**：
客户应付金额独立展示的代购模块；报价信息须在生成前完整。若提交折扣/抹零调整，成本和返点由老板在决定该调整前补齐，不并入项目毛利。

**预计成本 / 预计毛利**：
报价快照用于签约前决策的成本估算，以及调整后销售金额减预计成本所得金额和比例。
_Avoid_: 实际采购、付款或财务利润

**客户版导出**：
从当前非审批中的已报价版本或已批准版本生成的 PDF/XLSX，只含客户报价字段和施工说明。
_Avoid_: 成本、毛利、返点、审批信息

## V1 半包报价模型

**报价分区**：
项目级通用工程或项目空间。空间分区固定保存版本生成时的名称、类型、面积、周长和层高。

**报价行**：
V5 模板中的一个标准工程项快照，包含选择状态、数量来源、数量、销售价、成本价和对应金额。

**手工数量**：
老板或项目主案填写的数量；清空表示未选择，不计价，也不形成阻断。

当前草稿（含历史派生草稿）主动修改半包选中状态或有效数量时，保存事务同时同步本次变化来源行的瓷砖需求；取消项移除对应需求，数量变化更新对应需求。同步失败则整次保存回滚。此操作不升级绑定主材库、不改变其他选型及商品单价、折扣或抹零，不改写历史版本；仅打开派生草稿仍保持原快照，不自动同步。

**自动数量**：
由已确认规则基于项目外框面积、空间面积、空间周长与层高，或稳定工程项引用计算的数量。修改空间参数只重算受影响自动项，手工数量保持不变。

**标准价 / 成本价快照**：
草稿创建时从已发布 V5 主材库版本取得的不可变单价。编辑者不能在报价中覆盖。

**直接费**：
所有已选择且具有有效数量的工程项销售金额之和。

**管理费**：
半包末尾固定单位“套”、数量 1、金额为半包直接费的 10%；进入报价总额、毛利、版本和导出，但不计入 178 个标准工程项。

**调整后报价**：
已报价版本拟应用模块折扣和抹零后的客户金额；`PENDING_APPROVAL` 期间仅供老板结合预计毛利决策，不替换生效的基础报价，批准后才生效。

## V1 半包报价不变量

- 权威数据是 `半包报价单_v5.xlsx` 的 8 分区、178 个标准工程项；分区项数为 19/52/47/3/34/3/17/3，销售价 178/178、成本价 178/178、有效数量公式 39 个，导入校验须为 0 个阻断项。
- 发布新主材库版本时，只同步当前草稿中同一标准工程项的施工说明；不改单价、数量和已报价/已退回/已批准历史快照。
- 客餐厅勾选包阳台时显示“客餐厅（包阳台）”，装载客餐厅 52 项及“七、阳台工程”3 项；独立生活阳台装载“二、客餐厅工程”的完整 52 项，不再使用 `BALCONY` 分区 3 项。本确认不改变客餐厅包阳台及数量计算规则。
- `600*1200mm地砖（水泥砂浆粘贴）`和“防水石膏板吊平顶”默认不选且数量为空，由主案手工填写；`100*100mm`、`200*200mm` 小砖归入水泥砂浆粘贴组，旧 `70*200mm`、`70*300mm` 名称分别显示为 `50*200mm`、`60*200mm`。只修复当前草稿，历史快照不改写。
- 厨房复用厨卫 34 项，但排除“下沉式淋浴房工艺”和“壁龛工艺增加”，因此显示 32 项；卫生间保留 34 项。
- 未选择、手工数量为空或数量为 0 的行不计价、不导出、不产生虚假错误；普通行以有效数量表达选择，多型号组保留多选交互。
- 销售金额、成本金额、分区小计、直接费、管理费、调整后总价和毛利只由服务端计算；内部 4 位小数，页面与导出 2 位。
- 行销售金额 = 数量 × 销售价快照；行成本 = 数量 × 成本价快照；半包预计毛利 = 调整后报价 − 预计成本。
- 半包不另计税金；项目成本分析的客户应付金额、Excel/PDF 导出总造价均不加 6% 税金，工程汇总不再显示税金行。折扣和抹零仍仅在批准后生效。
- V5 中“正泰空开更换”“施耐德空开更换”的施工说明不含“单个电箱配置”；通过现有模板导入发布同步到当前草稿，历史报价快照不回写。
- 生产代码不执行 Excel 公式字符串，不新增未提供的局部尺寸、主材 SKU、木作或第三方字段。
- 老板、系统管理员和项目主案可编辑本人有权访问的草稿；木作、项目经理、财务及无关主案不可确认项目存在。
- 成本、毛利只返回给老板和系统管理员；主案的接口与页面不得获得这些字段。
- 成本毛利分区状态按报价版本保存的基准毛利率判定，默认 30%，仅老板和系统管理员可调整。
- 首次确认把 V1 草稿变为 V1 已报价，基础报价不需要老板审批；已报价或已退回继续编辑时建立连续新草稿；优惠调整由老板批准或打回并形成连续新版本。
- 已报价、已退回和已批准版本的报价头、空间和工程项不可原地篡改；折扣/抹零是已报价后的受控调整并独立留痕。
- 只有当前有效版本可以生成、调整、审批、打回或导出；失效页面操作返回冲突，不能覆盖新数据。
- 主案可以确认生成基础报价，并设置折扣/抹零；非默认调整必须填写原因并提交，不能自行批准。仅老板或系统管理员可批准、打回优惠调整，不提供特批。
- 客户版导出允许当前折扣 100%、抹零 0 且未提交调整审批的已报价版本，以及优惠调整已批准的 `APPROVED/CONFIRMED` 版本；`DRAFT`、`PENDING_APPROVAL` 和 `RETURNED` 不得作为当前正式报价导出。下载需要有效会话和项目权限，文件不得包含成本或毛利。
- 确认生成、继续编辑、折扣/抹零、批准、打回、导出及版本变化均记录操作人、时间、对象、结果和必要原因。
- 操作日志仅系统管理员可见；老板具有与管理员相同的业务权限，但无操作日志入口或接口权限。
