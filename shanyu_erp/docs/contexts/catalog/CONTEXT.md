# 主材库

管理报价所需的受控标准内容及其可追溯版本。

## Language

**标准工程项**：
可被报价选用的标准施工工序，拥有单位、施工报价、施工成本和数量规则。
_Avoid_: 主材、商品

**主材商品**：
项目可实际选择的品牌、型号、规格、颜色和图片的物料。
_Avoid_: 铺贴、安装等施工工序

**SKU**：
品牌、型号、规格和颜色组合确定的主材可选项。
_Avoid_: 只按品牌或品类合并的材料

**需求关联**：
定义某个标准工程项如何创建或更新一项主材需求。
_Avoid_: 将工程项直接绑定为某个固定 SKU

“多规格古堡砖”的“多规格”需求按品名“古堡砖”匹配；旧绑定库中品名为“瓷砖”、规格为 `200*200/200*400/400*400/400*600` 的同组商品亦可选择。普通瓷砖仍按规格匹配；状态、平方米单位、价格和颜色校验不放宽，不因此换库或改历史快照。

**瓷砖损耗**：
项目主材报价中由半包地砖/墙砖面积汇总生成的 15% 默认损耗；报价数量为来源面积乘 1.15，销售价和成本价本身不乘损耗。

> 2026-09-19 基线核对待确认：上句是旧文档口径；当前总表“类别规则”和代码使用 11.5%（×1.115）。尚无最新明确确认记录统一此冲突，本次不改变计算规则，也不据旧文档回退。
_Avoid_: 数量和单价同时乘 1.15

**玻璃移门**：
当前主材分类名称，替代旧称“木门”。
_Avoid_: 在新主材表单继续使用“木门”作为同一分类

**已发布版本**：
经治理后允许新报价引用的模板、价格或规则版本。
_Avoid_: 直接覆盖已被历史报价使用的记录

**导入批次**：
一次源 Excel 的文件哈希、来源行、解析结果和校验报告；校验阶段不能被报价引用。
_Avoid_: 上传成功即视为已发布

**半包模板版本**：
由零阻断导入批次一次性发布的 8 个报价分区、标准工程项和价格快照；当前正式版本以 `半包报价单_v5.xlsx` 为基线，发布后不可变。
_Avoid_: 把未发布的导入批次当成报价基准

## V1 当前半包模板基线

- V5 是当前正式半包数据基线；V4 仅作为历史对照和迁移来源，不作为当前验收基线。
- V5 包含 8 个报价分区、178 个标准工程项，销售价 178/178、成本价 178/178、有效数量公式 39 个，导入校验须为 0 个阻断项。
- V5 的工程项名称、单位、销售价和成本价与 V4 一致。V4/V5 语义级业务内容差异为 51 格：F 列 18 格、I 列 33 格。
- 历史“52 处差异”包含 `G202` 数组公式对象/序列化层差异；两版该公式和值相同，不属于语义级业务差异。
- 数量为空或 0 均表示未选择，不计价、不导出。生产代码不得执行 Excel 公式字符串，也不得把单元格地址写成业务逻辑。

## 定制浴室柜核心主材映射

- `material_id` 稳定标识“整柜型号＋核心主材颜色”组合；来源文件、工作表和行号仅用于追溯，不参与分组身份或颜色命名。
- 四种整柜型号为免漆/烤漆浴室柜的主卫、公卫款；`variantGroup` 为 `定制浴室柜:<整柜型号>`，页面仍显示四张柜型卡片。
- 《定制浴室柜主材库_v1.xlsx》提供核心主材选项，呈现为颜色；例如源型号“德利丰-洞石米白”映射为整柜型号和颜色“德利丰（大板）-洞石米白”。`colors` 与 `variantColor` 必须一致，已确认的同一材料颜色展示名保持稳定。
- 全量导入、发布、Delta 和在线编辑共用 `normalizeCabinetVariant`；每条柜型变体只对应一个核心主材颜色。图片关联按 `material_id` 保留，不能按源表行号或展示名重新绑定。
- 映射只调整整柜展示型号及颜色分组属性；整柜售价、成本、单位保持主材总表口径，核心板材价格不得覆盖整柜价格。已发布库及历史报价快照不回写。

## 主材总表导入与 0919 基线

- 当前总表快照为 694 条：ACTIVE 601、PENDING_DATA 89、INACTIVE 4；20K 木地板继续 ACTIVE，历史待确认备注不覆盖已确认状态。`catalog-0919.json` 是新增发布输入，旧 `catalog.json` 保留供历史迁移使用。
- 导入按 OOXML 命名空间读取业务单元格、共享字符串和公式缓存，不执行公式，也不因样式或表格对象不兼容而丢失业务数据；损坏压缩包、结构不兼容分别报错。
- FULL 读取“玻璃门选型”，按 `material_id` 保留顾朗/浴室柜分组及已登记图片；核验门框、玻璃颜色和资产引用。变更图片引用或未登记色卡应阻断，不能默用旧图。铝合金门套仅选门框颜色。
- FULL 发布记录版本至少为当前系统版本加 1；删除商品只从新库移除，不改历史版本。032 迁移仅自动升级已知0917基线，线上有额外编辑时要求受控导入，不自动覆盖。
- 草稿更新预览包含品名/项目；删除、停用或原颜色失效的选项提示不可用，用户确认更新后清空该选型并重新选择。历史报价不随主材库发布更新。

## 2026-09-19 零影响自动更新（用户最新确认）

- 每次主材库发布，在同一事务内分析当前首次编辑草稿（DRAFT、is_current、V1、无父版本且项目无其他报价版本）。部署迁移发布的库由升级脚本在迁移后调用同一分析器。
- 对已选商品同时比对旧库、新库和报价快照。品名、品牌、系列、型号、规格、单位、售价、成本、颜色选项、属性、说明和图片均无差异且当前选型有效，才更新库 ID 与商品版本 ID。数量、损耗、选色、金额、折扣抹零等业务内容一律不写；只增加 revision、更新时间和审计。
- 任一行有差异或不可用，整份报价跳过并输出逐字段影响；自动流程不得清空选型。原手动确认更新接口属于独立显式操作，不是自动流程入口。
- 非编辑版本及其派生草稿永久排除自动更新；继续编辑必须复制原库和原商品快照，不能采用最新库。新建首次草稿继续使用当前已发布库。
- 安全更新脚本、范围定义及本地隔离测试见 `../../operations/main-material-safe-update.md`。
- DELTA 发布只归一化本次改动商品，未改动商品的缺失资料、属性、状态等原样复制，避免小范围更正扩大为全库清洗。
- 主材选型列表的铂屿定制免漆/烤漆浴室柜，在“品牌 / 型号”下追加项目绑定库中同 material_id 的 configurationDescription；保留原型号、选色，不读取其他版本或改写报价快照、数量与价格。
- 云端部署调用必须固定目标 UUID、业务内容哈希和预览 planHash；停写窗口内归档预览后才能应用。技术失败停止放量，不把已提交的迁移误认为已回滚。详见 `../../operations/guarded-version-upgrade.md`。
