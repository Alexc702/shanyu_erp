# 组织与授权

定义谁可以在什么项目中查看或操作哪些业务信息。

## Language

**用户**：
可登录平台并被识别为具体操作人的内部成员。
_Avoid_: 客户、员工资料

**角色**：
用户在公司内的职责类型，如老板、主案设计师、木作设计师、项目经理、监理或财务。
_Avoid_: 项目指派

**项目指派**：
用户在某个项目上的具体参与关系和可见范围。
_Avoid_: 全局角色

**主案设计师**：
负责项目设计、报价和签约，可编辑被授权项目的主要报价模块，但不可查看成本或修改标准单价。
_Avoid_: 旧称“设计师”

**木作设计师**：
由主案设计师按项目指派，只能查看并编辑该项目的“铂屿木作定制”。
_Avoid_: 可访问整个项目报价的第二主案设计师

**敏感数据权限**：
独立控制成本、毛利、底价及可推导敏感信息的可见性。
_Avoid_: 只在页面上隐藏成本列
