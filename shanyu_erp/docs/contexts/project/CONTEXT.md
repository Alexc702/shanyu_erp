# 项目

定义跨报价、施工和财务阶段始终稳定的客户装修事项。

## Language

**项目**：
一个客户在一个装修场所上的完整业务事项，从报价到结项共享同一身份。
_Avoid_: 将报价项目、施工项目当成两个无关对象

**客户**：
委托并确认装修方案与价格的人或家庭。
_Avoid_: 账号、联系人

**场所**：
项目对应的实际房产和地址。
_Avoid_: 空间、房间

**空间**：
场所内用于组织工程量、报价和选材的可重复区域。当前类型为客餐厅、卧室、衣帽间、厨房、卫生间、阳台；每个实例另有 1—6 个字符的项目内唯一显示名称。衣帽间在项目中保留独立类型，半包报价复用卧室工程模板。
_Avoid_: 将 Excel 的“主卧/南次卧”视为不可新增的固定栏位

**客餐厅包阳台**：
客餐厅实例可使用阳台模板项目的业务标记；存在该标记时新增独立阳台必须二次确认。
_Avoid_: 把独立阳台与客餐厅内的阳台项目合并为同一空间

**项目阶段**：
项目当前所处的报价、签约、待开工、施工或结项阶段。
_Avoid_: 报价审批状态
