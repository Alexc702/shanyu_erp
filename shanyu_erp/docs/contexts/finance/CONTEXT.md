# 财务

管理项目签约后的资金流转、实际成本和结算结果。

## Language

**合同金额**：
客户签约时已确认的应收基准金额。
_Avoid_: 报价原价、当前项目金额

**当前项目金额**：
合同金额加上已批准工程变动后的当前应收口径。
_Avoid_: 已收款

**收款**：
客户已实际支付给公司的资金记录。
_Avoid_: 应收、合同金额

**付款**：
公司已实际支付给供应商、工人或其他收款方的资金记录。
_Avoid_: 预计成本

**实际成本**：
项目实际发生并经财务确认的成本。
_Avoid_: 报价中的预计成本

**实际毛利**：
基于实际收入和实际成本计算的结算结果。
_Avoid_: 报价阶段的预计毛利
