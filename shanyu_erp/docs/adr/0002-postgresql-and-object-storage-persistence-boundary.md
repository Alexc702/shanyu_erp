# 以 PostgreSQL 保存业务事实，以 S3 兼容对象存储保存文件

山屿 ERP 使用单一 PostgreSQL 集群保存关系化当前状态、不可变业务版本和追加式审计/财务记录，使用 S3 兼容 MinIO 保存合同、导出、材料图片和现场照片；数据库只保存文件引用、版本与哈希。该方案保留跨一期至三期的事务一致性和可查询性，同时避免事件溯源的查询复杂度、把大型二进制放入 PostgreSQL 的备份膨胀，以及业务代码依赖宿主机路径。

## Consequences

- 已批准报价、已发布模板、工程变动和财务入账使用数据库约束或追加记录保持历史。
- 文件模块必须在对象上传和数据库绑定之间处理未完成状态与孤儿清理。
- 现有 `half_package_exports.payload bytea` 在正式使用前迁移到 MinIO。
- PostgreSQL 和 MinIO 都必须异机备份；任一单独恢复后均要执行引用与哈希对账。
