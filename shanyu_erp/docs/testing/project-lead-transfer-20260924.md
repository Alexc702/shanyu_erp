# 项目主案转交本地验收（2026-09-24）

## 范围与实现

依据 V2 PRD V1.10（4.1、10.1、12、AC-V2-34～36）及最新 Pencil 18B～18F，仅实现主案转交和关联权限。

- 老板、管理员可选择另一启用中的主案；原因选填，保留原主案只读默认关闭。
- 最多一名只读人；再次转交清除更早关系，支持单独撤销。
- 只读人可看最新保存结果，但无编辑、确认、打印、导出、导出任务/旧文件下载、成本毛利权限。
- 权限修订号和项目事务锁防止并发及旧请求绕过；成功审计与负责人变更同事务。
- 报价、金额、主材、审批及已有导出快照不因转交重写。读取只读项目不创建或同步草稿。
- 页面焦点恢复时核验权限并放弃旧输入；工作台待办仅归当前主案。

## 验证过程中的失败及处理

- 首次 API 全量受前轮隔离测试残留项目影响，清理限定隔离测试项目后重新全量运行通过；未清理业务库。
- 浏览器首次在开发服务器跨页加载时达到整条用例时限；改用生产构建并延长整条流程上限后重跑，通过耗时 3.7 秒。
- 初次副本构建使用默认 Turbopack 路径失败；按项目实际配置 `next build --webpack` 在副本工作目录构建成功。
- 部署替身测试首次受沙箱禁止监听回环端口影响，允许本地监听后重新运行全部通过；不涉及云端。
