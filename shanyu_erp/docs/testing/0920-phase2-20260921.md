- Excel/PDF 在预算说明书后新增项目报价汇总，汇总半包、主材与设计费；未批准优惠不进入正式导出。

- 新迁移 033/034 仅在隔离测试库应用，未加入任何线上发布执行。

## 尚需确认或补验，不冒充通过

1. 图片对客安全标记（建议资产版本 + SHA-256 审核清单）的持久化方案需要用户确认。目前只有占位路径，不具备审核通过图片的实际导出能力。
2. 真实候选库发布 → 34A 选型 → 选材单图片全链路未执行；候选 JSON/资产校验与现有映射测试不能代替这条验收。
3. 项目资料外框面积修改入口到设计费同步的完整浏览器闭环尚未执行；现有报价面积参与服务端计价，不宣称该闭环已验收。
4. 新增选材单权限、并发任务复用、失败后原快照重试已有实现，但本轮独立 HTTP 样例只覆盖成功路径与恢复；异常路径尚需专门端到端覆盖。
5. 已检查所列代表页面和导出样张，无全画板逐像素一致的结论；超长项目地址封面、全部品类与实物图片混排还需扩展视觉验收。
6. 数量存储及计价精度仍沿用原规则；无用户确认前不改变。
