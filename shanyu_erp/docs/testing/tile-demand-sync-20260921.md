# 派生草稿半包编辑与瓷砖需求同步回归

日期：2026-09-21。范围仅限半包主动编辑后对应 AUTO_TILE 需求同步。

## 修复

- 复用现有主材需求同步逻辑，允许由半包保存事务调用。
- 在保存前以数据库数值比较找出选中状态或有效数量变化的来源行；只同步这些行。
- 同步和半包保存共用事务，异常一起回滚；保存响应包含最终修订号。
- 不取消派生草稿读取保护，不升级主材库，不修改历史版本或未编辑的选型。

## 边界

本轮未连接云端，未修改本地日常业务数据库，未提交、推送或部署。未进行浏览器手工验收；验证为真实隔离 PostgreSQL + 服务层专项、已有 API HTTP 回归及 Web 回归。部署脚本未修改，本轮未重跑部署脚本测试。

本修复不批量清理既有残留需求。将来部署后，已发生过不同步的旧草稿需重新勾选并取消对应半包项触发一次主动编辑，或另行确认定向数据修复；不能声称仅部署就已修复云端现有数据。
