# 山屿 ERP V1 完整验收用例

> 基线：半包报价 PRD V2.0、`山屿erp设计稿.pen`、`半包报价单_v3.xlsx`。  
> 范围：V1 半包报价；不验收施工、财务、主材 SKU 或木作定制明细。

## A. 环境与数据库

| ID | 用例 | 操作 | 预期 |
| --- | --- | --- | --- |
| ENV-01 | 环境自检 | `pnpm check:env:runtime`（服务运行时） | Node/pnpm/Docker/PostgreSQL/MinIO/Web/API 均通过 |
| DB-01 | 全新迁移 | 空数据库执行 `pnpm db:migrate` | 迁移 001–009 全部成功 |
| DB-02 | 种子幂等 | 连续执行两次 `pnpm db:seed` | 账号/项目/空间不重复，数据恢复为基准 |
| DB-03 | 迁移回滚 | 对迁移 009 执行 down→up | 可回滚并恢复，既有业务数据不变 |
| DB-04 | 报价头不可变 | 事务内修改已提交报价金额/毛利率 | 数据库拒绝 |
| DB-05 | 报价明细不可变 | 事务内修改已提交空间/工程项 | 数据库拒绝 |
