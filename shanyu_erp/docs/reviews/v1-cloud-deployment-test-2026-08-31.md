## 生产上线前剩余门禁

- 当前测试地址为 HTTP IP，只用于云端测试验收；真实用户启用前必须绑定域名、
  启用可信 HTTPS，并设置 `SESSION_COOKIE_SECURE=true`。
- 当前 2GB 测试机不启动 MinIO，导出文件仍在 PostgreSQL；正式生产需完成
  ADR-0002 的对象存储迁移、异机备份和隔离恢复演练。
- 正式生产应使用镜像仓库不可变 tag/digest，并为服务器配置只读拉取凭据。
- 真实并发量明确后需要进行压力测试和容量评估。
