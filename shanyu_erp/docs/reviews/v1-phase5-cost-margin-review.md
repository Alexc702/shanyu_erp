## 2. 实现结果

| 能力 | 结果 |
| --- | --- |
| 报价成本快照 | 报价固定引用不可变主材库版本，报价行保存成本单价与成本金额；新版本不回写历史报价 |
| 服务端计算 | 行、分区和半包预计成本/毛利统一使用十进制定点四位计算；页面显示两位 |
| 毛利口径 | 预计毛利 = 已计价工程项销售金额 − 预计成本；按设计稿不计入 V1 管理费 |
| 汇总页 | 还原销售金额、预计成本、预计毛利、毛利率、分区/空间表和客观状态 |
| 明细页 | 还原分区导航、成本快照版本、数量有效工程项及销售/成本/毛利列；零计价分区显示空状态 |
| 权限 | 仅老板可访问独立成本接口和两个页面；主案不显示入口，直达页面为 404，接口返回 403 |
| 审计 | 老板查看成本毛利记录独立审计动作，审计详情不复制敏感金额 |

页面基于项目现有 shadcn/ui 基础组件实现，并新增同风格 `Table` 组件；色彩、卡片、表格、状态标签和两栏明细布局与设计稿一致。

## 3. Excel 157 项对算

- 源表 8 分区、157 个工程项，销售价 157/157、成本价 157/157 均完整。
- 按源表缓存数量样例逐行执行 `数量 × 成本价`，再汇总分区和半包结果。
- 机械对算结果：直接销售金额 `113124.7660`、预计成本 `152142.8484`、预计毛利 `-39018.0824`、毛利率 `-0.3449`，系统结果与独立源表计算差异均为 `0.0000`。
- 负毛利是源表样例数据的真实计算结果，系统保留符号并正常显示，不擅自修正成本或设置未提供的告警阈值。

## 4. 权限与阶段边界

- 老板：可查看预计成本/毛利汇总、所有分区和数量有效工程项明细。
- 主案：继续编辑销售报价，但销售报价响应不含成本、毛利、成本版本；项目和报价页面均无成本入口。
- 木作、预留角色及非参与人：成本接口由服务端拒绝，且不泄露项目名称。
- 当前系统尚未建立阶段 6 的客户导出和日志展示页面，因此不存在从这些未实现传输面取得成本数据的路径；新增 DTO 只用于老板专属接口。
- 未实现施工执行、实际采购、财务流水、收付款、实际成本、实际利润、主材 SKU 或木作模板字段。

## 6. 用户验收重点

1. 老板进入“静悦府（演示）”，打开“查看预计成本毛利”，核对四项汇总和各分区状态。
2. 打开工程项成本明细，逐个切换分区；只应看到数量有效项，工作阳台应显示空状态。
3. 回到半包报价修改一项数量并保存，再查看成本页；销售、成本和毛利应同步重算，成本版本保持不变。
4. 使用主案账号进入同一项目：项目页与报价页无成本入口，直接访问成本页显示 404。
5. 确认全流程没有施工、收付款、实际成本或实际利润输入与文案。
