- 将隔离 API 数据库变量带入顶层 `pnpm test` 时，API/Web 均通过，但后续部署测试的临时 Compose 凭据被继承变量覆盖，发生认证失败。因此最终门禁分开执行：API/Web 使用指定隔离库；部署测试清除这些 POSTGRES/专项开关变量，使用其自身临时容器配置。没有改部署脚本，也不把该次顶层命令报告为成功。
